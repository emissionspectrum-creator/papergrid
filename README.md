# papergrid 國字書寫練習卷

產生 A4 橫放、直式書寫、稿紙格子的國字練習卷。國字右側附注音；點一下字可以改成「加框」（只顯示注音、國字位置空框），讓孩子看注音寫國字。

## 字型

從 <https://toneoz.com/blog/download-fonts/> 下載這兩套字型，解壓縮後放到 `fonts/`：

| 用途 | 字型 | 檔案位置 |
|---|---|---|
| 預設（國字＋注音） | 字嗨注音標楷 | `fonts/BpmfZihiKaiStd/BpmfZihiKaiStd-Regular.ttf` |
| 加框字（只有注音） | 字嗨注音加框 | `fonts/BpmfZihiBox-R/BpmfZihiBox-R.ttf` |

授權檔一併保留在各自的資料夾裡。檔名不同的話，改 `config.js` 裡的 `FONTS`。

## 啟動

```bash
./start.sh
```

會在 <http://127.0.0.1:8765/> 啟動 Python 內建伺服器並開啟瀏覽器（Brave → Chrome → 系統預設）。不能直接雙擊 `index.html` 用 `file://` 開，瀏覽器可能擋字型。換埠：`PORT=9000 ./start.sh`。

## 使用

- 左側文字框輸入文字。Enter 另起一個直行；連按兩次 Enter 空一行。
- 點右側預覽上的國字切換「加框」，再點一次切回。文字框會同步出現 `[字]` 記號；也可以直接打 `[字]` 或 `[小狗]`（框多個字）。
- 可調國字大小、邊界、換行方向（由右而左／由左而右）、格線開關。

## 輸出 PDF（Brave / Chrome）

按「列印 / 存成 PDF」（或 Ctrl+P）：

- 目的地：**另存為 PDF**
- 版面配置：**橫向**（頁面已指定 A4 橫放，通常會自動選好）
- 紙張大小：**A4**
- 邊界：**預設** 或 **無**（頁面已自己留邊界）
- 縮放：**預設**（100%，不要選「符合頁面大小」）
- 「更多設定」裡取消勾選 **頁首及頁尾**

## 調整字型比例

開 `test.html`（練習卷頁面上有連結）。同一批字用兩種字型並排，「重疊」列把標楷（紅色）疊在加框字上。用滑桿調整後，把下方產生的設定貼回 `config.js` 的 `FONT_ADJUST`。其他版面參數（格線顏色、預設大小、邊界、行距）也都在 `config.js`。

## 檔案

- `index.html` / `app.js`：主頁面
- `test.html` / `test.js`：字型比例測試頁
- `render.js`：共用的解析、版面計算、繪製
- `config.js`：所有可調參數
- `style.css`：畫面與列印樣式
